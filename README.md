# e-plantShopping - Paradise Nursery Shopping Application

Welcome to **Paradise Nursery**, an interactive and user-friendly online plant shopping web application!

## About the Project
This project was created as part of the final assignment to demonstrate a fully functional React application integrated with Redux for shopping cart management.

## Key Features
- **Landing Page**: A visually appealing landing page featuring a background image, company introduction, and a "Get Started" button.
- **Product Listing**: 
  - Over 6 plant options grouped into 3 distinct categories.
  - Interactive "Add to Cart" buttons that dynamically update cart state and disable once clicked.
  - Persistent navigation bar displaying total cart count.
- **Shopping Cart**:
  - Displays item thumbnail, name, unit price, and total cost per plant.
  - Full control over item quantities (increase/decrease/delete).
  - Calculates total order cost dynamically.
  - "Continue Shopping" button to return to the product page.
  - "Checkout" notification ("Coming Soon").

## Tech Stack
- **Frontend**: React, HTML5, CSS3, JavaScript (ES6+)
- **State Management**: Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **Build Tool**: Vite / Create React App
